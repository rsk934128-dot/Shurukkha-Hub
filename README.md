# Shurukkha Hub | সিরাজগঞ্জ সুরক্ষা 🛡️

**সিরাজগঞ্জ সুরক্ষা** একটি এআই-চালিত এবং ইভেন্ট-ভিত্তিক "District-Scale Mission-Critical Emergency Infrastructure"। এটি দুর্যোগপূর্ণ এলাকায় জননিরাপত্তা এবং দ্রুত ত্রাণ কার্য পরিচালনার জন্য একটি আধুনিক সমাধান। এটি এখন একটি **Sovereign Intelligence & Financial Grid** হিসেবে নূরআই (NoorAI) এবং ফিউশনপে (FusionPay)-এর সাথে একীভূত।

## 🚀 মূল বৈশিষ্ট্যসমূহ (Core Features)

- **Offline-First Survival Mode:** `DisasterStorage` লেয়ারের মাধ্যমে ইন্টারনেট বিচ্ছিন্ন অবস্থায়ও অ্যাপটি কার্যকরী থাকে।
- **Autonomous Dispatcher Engine:** Google Genkit AI ব্যবহার করে স্বয়ংক্রিয়ভাবে সবচেয়ে উপযুক্ত রেসপন্ডার নির্বাচন।
- **Forensic-Ready Audit Trails:** `audit_trails` কালেকশনের মাধ্যমে প্রতিটি ইমার্জেন্সি রেসপন্সের একটি অপরিবর্তনীয় SHA256withRSA রেকর্ড।
- **Sovereign Handshake:** নূরআই এবং ফিউশনপে গ্রিডের সাথে রাজকীয় ডিজিটাল সংযোগ (Developer Portal v21.0)।
- **Predictive Simulation Engine:** এআই-এর মাধ্যমে ভবিষ্যতের ঝুঁকির পূর্বাভাস এবং রিসোর্স প্রজেকশন।
- **Emergency Sovereign Lock:** এক ক্লিকে বাইরের সব API কানেকশন বিচ্ছিন্ন করার সক্ষমতা।

## 🛠️ টেক স্ট্যাক (Tech Stack)

- **Frontend:** Next.js 15 (App Router), React, Tailwind CSS, ShadCN UI.
- **Backend/Database:** Firebase Firestore, Firebase Authentication.
- **AI/GenAI:** Google Genkit, Gemini 2.5 Flash.
- **Interoperability:** RSA v2 Bridge, Universal Webhook Engine.
- **Persistence:** LocalStorage based DisasterStorage for offline resilience.

## 📂 প্রজেক্ট স্ট্রাকচার (Project Structure)

- `src/ai/flows/`: Genkit AI ফ্লো যা বন্যা ঝুঁকি, রেসপন্ডার এবং সিমুলেশন হ্যান্ডেল করে।
- `src/lib/integration-bridge.ts`: ইউনিভার্সাল এপিআই ব্রিজ এবং ডিজিটাল সিগনেচার সার্ভিস।
- `src/lib/sovereign-connector.ts`: নূরআই এবং ফিউশনপে হ্যান্ডশেক লজিক।
- `src/lib/orchestrator.ts`: অটোনোমাস কমান্ড লজিক।
- `src/components/dashboard/`: ডিসপ্যাচার কনসোল এবং সিটিজেন ড্যাশবোর্ড কম্পোনেন্টস।

## 📈 ভ্যালু প্রপোজিশন (Value Proposition)

1. **Resiliency:** চরম দুর্যোগেও এটি অচল হয় না (Offline-First)।
2. **Accountability:** ফরেনসিক অডিট লগের মাধ্যমে স্বচ্ছতা নিশ্চিত করে।
3. **Efficiency:** এআই-এর মাধ্যমে দ্রুততম সিদ্ধান্ত গ্রহণ।
4. **Sovereignty:** নূরআই ও ফিউশনপে ইন্টিগ্রেশনের মাধ্যমে একটি স্বাধীন ইন্টেলিজেন্স গ্রিড।
