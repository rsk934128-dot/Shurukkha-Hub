# **App Name**: Shurukkha Hub

## Core Features:

- One-Touch SOS: A high-visibility dashboard button to trigger local alerts and provide instant coordinates for emergency response teams.
- River Intelligence Tool: An AI tool that analyzes weather data and Jamuna water levels to generate specific, hyper-local survival and evacuation advice for charchar (river island) inhabitants.
- Flood & Disaster Alerts: Real-time visual integration showing current water levels of the Jamuna river with danger-level color coding.
- Interactive Resource Map: A client-side map displaying the location of the nearest shelters, medical facilities, and fire stations in the Sirajganj district.
- Emergency Directory: A rapid-access digital phonebook for local police, hospitals, and civil defense units.
- Live Incident Reporting: A simplified UI form to submit local safety incidents like traffic blockages or theft, stored in local storage for local situational awareness.
- Offline Emergency Handbook: PWA capabilities to store vital local survival and rescue numbers directly on the user's browser for network-less scenarios.

## Style Guidelines:

- The design utilizes a sophisticated dark color scheme inspired by deep river currents and high-stakes reliability.
- Primary color: A vibrant Royal Blue (#7597FF) used for critical indicators and interaction elements, derived from deep-water security concepts.
- Background color: A deeply desaturated midnight navy (#14171F) to provide high contrast for critical alerts.
- Accent color: A brilliant Cyan-Blue (#1AD1FF) for highlight items and active reporting features, creating an analogous energy alongside the primary color.
- Headline font: 'Space Grotesk' for its machined and technical appearance, conveying scientific precision in emergency scenarios.
- Body font: 'Inter' used for text-heavy reporting and bulletin updates, ensuring maximum legibility across all device types.
- A mission-control inspired layout with card-based modular sections for SOS triggers, weather forecasts, and river telemetry.
- Pulsating rings around the SOS button and smooth drawer transitions to keep the interface feeling responsive during critical operations.
